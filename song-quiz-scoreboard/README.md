# BLC 听歌猜曲自觉积分榜 0.3.3

## 0.3.3 端口迁移

- 管理页与 OBS 服务端口由 12454 迁移到 18454，以降低与客机现有服务冲突的概率。

## 0.3.2 重连行为简化

- BLC 重连固定为每 5 秒一次，仅连接本机服务。
- 移除随机抖动和指数退避，降低安全软件的可疑网络驻留特征。

## 0.3.1 持久性修补

- BLC WebSocket 短暂断开时自动重连，不再关闭 OBS 展示服务。
- OBS 页面启动时通过 HTTP 读取完整榜单、场次和设置快照。
- OBS 场景恢复、页面恢复和网络恢复时主动重新连接并同步数据。
- 管理页、展示页和 API 禁止缓存，避免 OBS 长期使用旧页面。

## 本版规则

- 插件启动后默认处于待机状态，不接受计分。
- 管理页点击“开始新活动”后，清空上一场结果并开启本场计分。
- 弹幕去除首尾空格后完整等于 `+1` 时增加 1 分，完整等于 `+2` 时增加 2 分。
- 管理页可设置最低粉丝牌等级；`0` 表示关闭验证，正数表示只接受等级不低于门槛的弹幕。等级字段缺失时同样拒绝。
- `我也+1`、`+10`、`+2加油` 等普通聊天不会计分。
- 点击“结束本次活动”后停止接收分数，OBS 保留并展示本场最终榜单。
- 再次点击“开始新活动”才进入下一场，并清空上一场积分。
- 当前版本不将积分长期写盘；关闭 BLC 后本场积分消失，绝不会跨活动累计。周榜、月榜应在未来使用独立的长期数据层实现。

## 管理功能

- 本地测试 `+1`、`+2` 以及不同粉丝牌等级。
- 开始新活动、结束活动、清空本场积分。
- 直接设分、手动加减 1 分、删除用户。
- 同分用户并列，默认在 OBS 展示前 10 名。
- 配置最低粉丝牌等级、榜单标题、字号、标题色、用户名颜色、积分颜色、面板颜色和透明度。
- 查看 BLC 事件、读取弹幕、成功计分、非指令、未开场拒绝和粉丝牌拒绝数量。

粉丝牌等级取自 BLC 转发的弹幕事件。标准事件可提供等级，但不保证包含可供插件可靠比对的粉丝牌所属直播间 ID，因此本版只验证事件中的等级值。

## 安装与地址

1. 将整个插件目录复制到 BLC 1.10.3 的 `data/plugins` 目录。
2. 在 BLC 中启用插件并完全重启 BLC。
3. 确认 BLC 房间设置已开启“通过服务器转发消息”。

- 管理页：http://127.0.0.1:18454/admin
- OBS 浏览器源：http://127.0.0.1:18454/overlay/song-score

插件使用 18454 端口，可与 12451 的像素气泡插件及使用 18453 的心愿墙插件同时运行。
