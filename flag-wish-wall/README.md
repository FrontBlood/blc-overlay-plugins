# BLC Flag 心愿墙 0.3.2

## 0.3.2 滚屏更新队列

- 当前一轮滚屏期间发生的记录或展示配置变化不会立即重启动画。
- 变化会合并为一份最新状态，在当前内容完整滚出画面后统一应用并开始下一轮。
- 30 秒校准只比较已发布记录和真实展示配置，不再因连接状态或统计计数变化重置滚屏。

## 0.3.1 副词保留整条弹幕

- 副激活词仅用于判断弹幕是否包含关键词；命中后整条原始弹幕入库，不再从副词后方截取。

## 0.3.0 多副激活词

- 管理页可通过“添加副词”维护多个副激活词，并可逐项删除。
- 所有副词均全文匹配且忽略英文大小写；一条弹幕命中多个副词仍只入库一次。
- 旧版单个 `secondary_flag` 配置启动时会自动迁移为 `secondary_flags` 列表。

## 0.2.1 用户名分隔

- OBS 滚屏中用户名与心愿正文之间固定保留一个空格，横排和竖排一致。

## 0.2.0 主副激活词

- 主激活词仅在弹幕句首匹配，英文字母不区分大小写，例如 `Flag`、`flag`、`FLAG` 等价。
- 副激活词在弹幕任意位置匹配，可配置为自动加入滚屏，或仅入库等待管理页审核。
- 同一弹幕同时满足主、副词时以主词为准，每条弹幕最多产生一条记录。
- 历史记录自动视为已发布，数据格式向后兼容。

## 0.1.11 端口迁移

- 管理页与 OBS 服务端口由 12453 迁移到 18453，以降低与客机现有服务冲突的概率。

## 0.1.10 重连行为简化

- BLC 重连固定为每 5 秒一次，仅连接本机服务。
- 移除随机抖动和指数退避，降低安全软件的可疑网络驻留特征。

## 0.1.9 持久性修补

- BLC WebSocket 短暂断开时自动重连，不再关闭 OBS 展示服务。
- OBS 页面启动时通过 HTTP 读取完整快照，WebSocket 不可用时仍会定期自愈。
- OBS 场景恢复、页面恢复和网络恢复时主动重新连接并同步数据。
- 管理页、展示页和 API 禁止缓存，避免 OBS 长期使用旧页面。

## 默认规则

弹幕中出现区分大小写的 Flag 后，插件会记录其后的全部内容，默认不限制字数。只有粉丝牌等级达到 3 级才会记录；BLC 消息中缺失粉丝牌等级时默认拒绝。

示例：Flag希望今天直播顺利。

同一用户可以提交多条内容。记录持久保存在 records.json，重启后仍然存在。

## 管理页可配置项目

- 展示抬头：默认“心愿墙”，展示格式为“★自定义抬头★：”
- 弹幕激活词：默认 Flag
- 屏蔽词：使用中文全角分号
- 最低粉丝牌等级：默认 3；设为 0 可取消门槛
- 单条字数上限：默认 0，表示不限；填写 1～500 的正数才会截断
- 文字排布：竖向文字或横向文字
- 滚动方式：从下向上或从右向左，与文字排布独立选择
- 滚动速度：默认 38 像素/秒

横向文字配合左右滚动时以单行跑马灯展示；横向文字配合上下滚动时按展示宽度换行上浮。保存后展示窗实时更新，无需重启。管理页可以逐条删除已记录内容。

## 地址

- 管理页：http://127.0.0.1:18453/admin
- OBS 浏览器源：http://127.0.0.1:18453/overlay/wish-wall

插件使用 18453 端口，可与使用 12451 的像素气泡插件同时运行。直播间由 BLC 当前配置决定；BLC 短暂断开时展示服务保持运行并每 5 秒尝试恢复连接。

- 用户内容原样转录，不自动添加句号；用户名与内容之间始终保留一个默认间隔，不依赖观众输入空格；条目分隔符可在管理页自定义并保留输入的空格。
- 字体颜色、字号和描边统一控制抬头、用户名与记录内容，保存后实时更新。
- 展示文字不使用阴影；描边可单独开关，并可配置颜色和宽度。

## 接收诊断

最低粉丝牌等级设为 0 时完全跳过粉丝牌字段验证，可用于测试 BLC 消息链路。管理页会分别显示 BLC 事件、可解析弹幕、缺少激活词、牌子拒绝和成功记录数量。

如果 BLC 事件始终为 0，请在 BLC 房间设置中开启“通过服务器转发消息”，否则插件不会收到直播间消息。

## 文字排布、用户名与分隔

- 竖向文字：中文逐字直立；用户名、抬头和内容中的连续大小写英文字母保持为一个整体，以约 65° 斜向斜体顺应纵列，不拆成逐字母竖排。
- 横向文字：所有用户名与内容正常横排，不旋转英文。
- 不同用户条目默认使用五角星 ★ 分隔，可在管理页改为任意不超过 12 个字符的短文本。
- 新捕获内容加入展示队列头部，优先滚入画面。
